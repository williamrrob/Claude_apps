# Etymological Consolidation Plan

## Objective
Organize 71,406 consolidated lemmas by etymological origin into proper word families.

## Strategy

### Phase 1: High-Frequency Words (Core vocabulary)
- Start with most common English words
- Establish clear family structures
- Verify etymologies via web search for accuracy
- Goal: 500-1000 words organized as proof-of-concept

### Phase 2: Common Derivatives
- Expand families with related derivatives
- Consolidate inflections within etymological groups
- Track parent-child relationships

### Phase 3: Remaining Dictionary
- Organize remaining ~70k words
- Handle edge cases (mixed origins, uncertain etymologies)
- Cross-reference with existing structured families

## Etymological Origins to Track
- **Latin roots** (capere, dicere, ducere, ferre, mittere, scribere, specere, cedere, pendere, petere, tenere, facere, tractare, etc.)
- **Greek roots** (anthropos, kratos, phobos, sophia, logos, etc.)
- **Germanic/Proto-Germanic** (stand, break, drink, sing, spin, bind, bring, build, grow, speak, etc.)
- **French** (from Old French/Norman French)
- **Mixed/Uncertain** (words with unclear or mixed origins)
